### 02. Arduino Sensor & Actuator Experiments

**Embedded System Practice**

다양한 센서와 액추에이터를 Arduino에 연결하고, 입력 데이터에 따른 출력 제어를 실습했습니다.

- **MPU6050:** 가속도 및 자세각(Roll, Pitch, Yaw) 측정 실습
- **Ultrasonic Sensor:** 거리 측정 및 조건 기반 제어
- **TCRT5000:** 적외선 반사 신호 측정
- **Sound Sensor:** 소리 감지 기반 동작 제어
- **DC Motor:** L298N 모터 드라이버를 이용한 구동
- **Servo Motor:** 각도 제어 및 간단한 자동화 동작

### 03. Parking Gate Control Using FSM

**Arduino-Based Automatic Parking Gate**

초음파 센서로 차량을 감지하고 서보모터와 LED를 제어하는 주차장 차단기 예제를 구현했습니다.

- 차량 감지 거리 조건 설정
- FSM을 이용한 차단기 상태 전환
- 서보모터를 활용한 차단기 개폐
- 적색·녹색 LED를 통한 상태 표시
- 차량 통과 후 1초 유지 조건 구현
